# Ai机器人社区 · airobot-comm
桌面AI机器人社区，致力于打造轻量化、可扩展的桌面airobot应用框架，推动AI机器人在学习/陪伴/商务领域的商业应用。
目前基于开源和商业化版本的多款产品，已经在商业服务、儿童学习陪伴、老人康养服务等领域商业化运营；

## 🌟 核心项目
| 项目名称 | 项目简介 | 地址 |
|----------|----------|------|
| airobot-assistant | 轻量、功能可扩展的语音服务桌面AI机器人助手，支持多类场景功能扩展，支持小智ai，coze，dify等云端智能体集成，作者ronnie | [airobot-assistant](https://github.com/airobot-comm/airobot-assistant) |
| WaitAgent    | 轻量Vibe Agent会话管理终端，一个终端管理多个vibe Agent，让Vibe并行开发省心，高效，真正专注心流，作者kikakkz | [wait-agent](https://github.com/airobot-comm/wait-agent) |
